# RTS 0.1.0

Навчальна стратегія в реальному часі для Windows x64. Керуйте робітниками й військом, добувайте золото, будуйте та покращуйте споруди, навчайте юнітів і захищайте базу від комп’ютерного супротивника. У грі є три рівні складності, туман війни, мінікарта та локальні JSON-збереження. Для перемоги знищіть усі завершені ратуші супротивника.

## Запуск у Unity

1. Встановіть через Unity Hub **Unity 6.3 LTS (6000.3.29f1)** із підтримкою збірки Windows через Mono. Проєкт використовує URP та Input System.
2. Додайте в Unity Hub кореневу папку репозиторію з каталогами Assets, Packages і ProjectSettings. Дочекайтеся імпорту.
3. Відкрийте [RtsMainMenu.unity](Assets/Scenes/RtsMainMenu.unity) і натисніть Play. Виберіть «Нова гра», складність і підтвердьте старт у вступному вікні.

## Керування

| Дія | Керування |
|---|---|
| Вибір | ЛКМ по власному юніту або споруді. Для рамки утримуйте ЛКМ і тягніть мишу. |
| Наказ | ПКМ по землі або об’єкту. Дія залежить від цілі й типу юніта. |
| Зупинка вибраних юнітів | Клавіша S. |
| Будівництво | Виберіть робітника й тип споруди на HUD. Підтвердьте розміщення ЛКМ. Escape або ПКМ скасовує розміщення. |
| Камера | Підведіть курсор до краю ігрової області. Колесо змінює масштаб. ЛКМ на мінікарті переміщує камеру. |
| Пауза | Escape або кнопка меню праворуч угорі. Якщо активне розміщення споруди, перший Escape скасовує його. |

Режим екрана й роздільність змінюються в головному меню або на паузі. Збереження на Windows лежать у %USERPROFILE%\AppData\LocalLow\DefaultCompany\RTS\Saves.

## Windows x64 збірка

1. У Unity відкрийте **File → Build Profiles** і виберіть профіль Windows.
2. У списку сцен профілю залиште активними Assets/Scenes/RtsMainMenu.unity першою та Assets/Scenes/RtsMatchPrototype.unity другою. Для релізу вимкніть SampleScene й інші тестові сцени.
3. Виберіть архітектуру x86_64 і Mono. Вимкніть Development Build.
4. Натисніть **Build** і збережіть `RTS.exe` в новій порожній папці, наприклад `Builds/Release/RTS-0.1.0-Windows-x64/`. Для запуску поза редактором відкрийте `RTS.exe` з цієї папки. Зберігайте його разом з `RTS_Data` та рештою файлів, створених Unity.

## Інсталятор

Потрібен Inno Setup 6 із файлом локалізації Ukrainian.isl у каталозі Languages. Запустіть команду з кореня репозиторію, підставивши шлях до ISCC.exe та папку свого релізу.

~~~powershell
.\Installer\Build-Installer.ps1 -Iscc 'C:\Path\To\ISCC.exe' -Release '.\Builds\Release\RTS-0.1.0-Windows-x64' -Output '.\Builds\Release\Installer'
~~~

Команда вище створює `Builds/Release/Installer/RTS-0.1.0-Windows-x64-Setup.exe` і виводить його контрольну суму. Пакуйте свіжу збірку гри без діагностичних модулів і зберігайте вихідні файли збірки та інсталятор у `Builds/`. Інсталятор дає вибрати папку гри, додає ярлик у меню «Пуск» і пропонує ярлик на робочому столі. Видалення гри зберігає локальні збереження. [Скрипт пакування](Installer/Build-Installer.ps1) · [Конфігурація інсталятора](Installer/RTS.iss)

## Відомі обмеження

- У штучному бою з 50–90 юнітами зафіксовано тривалі кадри й відставання ігрового часу. У прогоні попередньої збірки P99 становив 78,12 мс, максимум — 862,09 мс. [Умови й результати стрес-тесту](Installer/KnownIssues.uk.txt)
- Windows 11, мінімальна конфігурація та масштабування Windows 125% і 150% залишаються неперевіреними.
